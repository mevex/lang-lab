# Lang Lab
A space for exploring programming languages, their implementations, and the technology behind them.

My starting point on this journey is [Crafting Interpreters](https://craftinginterpreters.com/) by Robert Nystrom. I am closely following the code presented in the book, but with small changes to better suit my taste. Along the way, I want to experiment with this implementation as much as possible to get a better understanding of the subtleties hidden behind the author's design decisions. The goal of the project is to understand the inner workings of compilers and interpreters, demystifying them, not to create yet another language that will (not) replace C++.

## Project Scope
My current goal is to implement both the tree-walk interpreter and the bytecode virtual machine presented in the book, following the chapters in order. Along the way, I want to tackle the chapter challenges that I find interesting and explore as many of the topics mentioned but left out of the book's implementations for practical reasons. I may even incorporate some ideas of my own.

### Beyond the Book
I would like to use the tree-walk interpreter to play around with language design by introducing new features, such as syntactic sugar like `+=` and prefix and postfix `++`, extending the language's built-in standard library and anything that will stir my curiosity or I simply want to add for fun. The virtual machine also offers a good starting point to explore exciting lower-level concepts. I could try and get my hands dirty with topics like code optimization, vectorization and even JIT. Or, I could try translating the generated bytecode into LLVM IR, or generating LLVM IR directly, and using it to compile a native executable.

Basically, the only limit to this project's future is my free time. For now, let's finish the book!

## Implementation and Build
The tree-walk interpreter is written in C# instead of Java, mainly because I'm more familiar with it. The bytecode VM will be written in C++, following a C-style approach while taking advantage of a few C++ language features. I enjoy implementing my own data structures, having control over these details and knowing what's happening under the hood.

### Prerequisites
**For SharpLox, the tree-walk interpreter:**
- Visual Studio with the .NET desktop development workloads installed.
- The .NET 10 SDK.

**For CLox, the bytecode VM:**
- Visual Studio with the Desktop development with C++ workloads installed.

### Getting Started
1. Clone the repository.
2. Open CraftingInterpreters.sln.
3. In Solution Explorer, select the project you want to run and press F5 to build and run the project.

### Running
**SharpLox**

Select one of the available launch profiles, depending on how you want to run the interpreter:
- REPL Run: starts the interpreter in interactive mode.
- File Run: runs the interpreter against a source file. By default it looks for a test.lox file inside the build directory.

**CLox**

The project currently contains the default Hello World program and will evolve as I work through the book.
